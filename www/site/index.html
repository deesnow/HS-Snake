Jeeves

A Discord bot for Hearthstone: decode deck codes, visualise decks, search cards, look up legend ranks, and auto-detect deck codes posted anywhere in your server.

➕ Add Jeeves to your server

Deck Commands

Decode, analyse, and visualise any Hearthstone deck code.

/deck <code>

Decode a deck code and display a card list with rarity icons, mana cost, format label, and total dust cost. Decks containing E.T.C. Band Manager or King of the Underbelly show their sideboard cards in a separate section.

/deckanalyze <code>

Detailed grouped analysis: cards split by type (Minions, Spells, Weapons, Locations, Heroes), subtype/tribe info, a mana curve bar chart, and dedicated sideboard sections when present.

/deckimage <code>

Render a visual image of the deck with card thumbnails. Sideboard cards are included after the main deck cards.

Card Commands

Look up any Hearthstone card by name.

/card <name>

Look up a single card by name and display its full card image.

/cardsearch [name]

Interactive card search with dropdown filters for Mana Cost, Class, and Card Type; paginated results (10 per page, up to 100); click any result to view its card image.

Legend Rank Commands

Register your BattleTag and track your ranked ladder progress across EU, US, and AP.

/rankset <battletag>

Register your BattleTag (Name#1234) for legend rank tracking across all three regions.

/rankremove <region>

Remove your BattleTag registration for a region (EU / US / AP).

/rank [mode] [region]

Show your current legend rank across all registered regions. Optional filters for game mode (Standard, Wild, Classic, Battlegrounds, Battlegrounds Duo, Arena, Twist) and region.

/rankchart <mode> <region> [season] [timeframe] [rank_type]

Render a line chart of your rank progress (Bronze through Diamond and Legend combined) over a season.

/rcc <mode> <region> [season]

Render a daily rank candlestick chart showing your open/close/best/worst rank each day.

Guild Leaderboard

See how your server's members stack up against each other.

/glb <region> <mode> <top> [season]

Show a leaderboard of ranked season scores filtered to members of your Discord server. Choose how many results to show (10 / 20 / All) and the current or previous season. Scores are computed with the Fair Hearthstone Rank Score model, below.

Fair Hearthstone Rank Score (FHRS)

The scoring model behind the Guild Leaderboard. It balances daily peaks, field density, and consistency, so the result reflects season-long performance rather than a single lucky day.

1. Daily Performance Score (DPS)

At the end of each day, the system records your highest rank achieved (R) and the total number of Legend players (N) in your region. 

DPS = log10(N) × ((N − R + 1) / N) × 100
  • log10(N) — the inflation factor: accounts for field density, since a Top 10 finish against 20,000 players requires far more than against 30 players.
  • (N − R + 1) / N — your percentile standing within the current Legend pool.
  • × 100 — scales the fraction into a human-friendly integer score.

2. Season Score

The final Season Score is the cumulative average of daily scores, divided strictly by the elapsed days of the season — so early grinders and late-month entrants are compared fairly. 

Season Score = (DPS₁ + DPS₂ + … + DPSₙ) / n

n is the current day of the season. Entering Legend mid-season scores 0 for the days before entry, lowering the seasonal average and rewarding sustained competition over the whole month.

Why it's fair

  • Anti-camping — hitting an early high rank and stopping lets your relative score degrade as the field grows.
  • Consistency-weighted — drastic rank drop-offs lower your daily average, favoring stable top-tier performance.
  • Self-scaling — automatically adjusts for regional player-pool growth across the season.

HDT Token

For use with the Hearthstone Deck Tracker RankTrackerPlugin.

/hdttoken

Generate a bearer token for the Hearthstone Deck Tracker RankTrackerPlugin, delivered via DM. Regenerating a token invalidates the old one.

Admin Commands

Grouped under /botadmin. All subcommands require the configured admin role, Administrator permission, or server ownership.

/botadmin setrole <role>

Set the role that is allowed to manage bot settings (requires Administrator permission).

/botadmin autodetect on|off

Enable or disable automatic deck-code detection for this server.

/botadmin allchannels on|off

on — monitor every text channel. off — only channels on the watch list.

/botadmin addchannel <channel>

Add a channel to the deck-detection watch list.

/botadmin removechannel <channel>

Remove a channel from the deck-detection watch list.

/botadmin status

Show the current bot configuration (admin role, auto-detect state, monitored channels).

/botadmin reloadcards

Force-refresh the Hearthstone card database on demand.

Auto-Detect

Jeeves can passively monitor channels for Hearthstone deck codes — no command needed. When a deck code is posted in a watched channel, the bot replies with a decoded deck image automatically. @mention + deck code always triggers a reply, regardless of channel settings. Fully configurable per server via the Admin Commands above.
